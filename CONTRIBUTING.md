# Contributing

Contributions should remain within the direct robot-space SGDiT scope of this repository.

1. Open an issue describing the bug, reproducibility gap, or proposed change.
2. Keep changes focused and avoid committing datasets, checkpoints, generated outputs, credentials,
   or machine-specific paths.
3. Add or update tests for behavioral changes.
4. Run `pytest` and `ruff check .` before opening a pull request.
5. Preserve the copyright and license header in source files.

By contributing, you agree that your contribution is licensed under the repository license.
