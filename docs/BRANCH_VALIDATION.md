## Cache completeness and package checks

The legacy extractor could truncate a long transcript to 64 and save `n_tokens=64`. The loader
now rejects such unverifiable caches. New raw caches carry complete-token extraction provenance;
archived V2 files require a manifest with a published fixed SHA. All **18,229** archived files
were checked against the original independent full-token/time audit before file identities were
pinned. No model weights, attention math, or input tensors were changed.

- CPU regression suite: **52 passed, 1 skipped, no failures** (53 tests).
- The skip is MuJoCo absent from that CPU environment; real rendering passed separately below.
- Ruff and diff checks passed. [GitHub CI](https://github.com/Mondo-Robotics/ECHO-G/actions/runs/36533786949) passed for the implementation commit.
- [Cache audit](../validation/cache_provenance_acceptance.json), [test summary](../validation/test_summary.json), [manifest identity](../manifests/v2_frozen_conditions.json).

## Numerical comparison

Against archived predictions, maximum elementwise physical39 difference is **6.038696e-6**;
0/3,242 clips are bitwise equal and 3,183 pass `atol=rtol=1e-6`. These mixed representation
channels are not a single distance in meters. The full-set result is not labeled bitwise parity.

For the five clips with the largest archive differences, the new package and validated V2
reference were rerun with identical state, inputs, noise, batch, and GPU. All six comparisons
(one batch of five plus five singleton batches) gave **maximum difference 0** for velocity,
Euler8 output and physical motion. Changing batch composition within the same implementation
produced a maximum difference of **5.565584e-6**. This establishes batch sensitivity, but does
not uniquely identify the cause of the historical archive differences.

## Real raw input to motion

Three original BEAT2 WAV/word-time inputs (8, 73 and 247 tokens) passed actual audio extraction,
text extraction, merge, provenance checks, signed-time construction and best15k sampling.
Every feature and final motion tensor is bitwise equal to the independent same-environment
reference. Ground-truth motion is not required for raw inference.

**Historical frozen-feature reproduction did not pass.** Audio max errors are 0.001953125,
0.01953125 and 0.013427734375 versus the retained 0.001 threshold. Text-token max errors are
0.25, 0.375 and 3.0; the longest example exceeds the retained 0.5 threshold. Word-derived token
times remain exact, and sampled-motion errors remain within the original motion thresholds.
The recorded encoder asset hashes match the earlier validation; the numerical cause has not
been isolated. The benchmark above uses frozen conditions, not newly extracted raw features.

## Real G1 MuJoCo render

The package exported and rendered its new prediction for
`english_1_wayne_0_100_100_utt_0000` with the actual G1 XML and 35 meshes: **312 frames,
30 FPS, 960×720, 10.4 seconds**, with the corresponding audio. Frame inspection showed the
real robot, ground and gestures. External assets and media are not bundled in the code repository.
The remote EGL loader was missing, so the same public pipeline was run in an isolated local
environment with MuJoCo 3.10.0. No renderer source changes were required.
The renderer was installed from the recorded working-tree snapshot based on `7043f2f`;
its export/render modules, wrappers and evaluation utilities are byte-identical to those
in `0605503`. Its prediction input comes from the new `0605503` full-set inference run.
The render report retains the actual snapshot hashes rather than relabeling that whole
snapshot as the later commit.
